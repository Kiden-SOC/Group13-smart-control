# Test Folder

Use `test_scenarios.md` as the shared checklist. Record ESP-IDF version, simulator, build result, date, tester and observed output. **Do not mark a test as passed until it was actually run** after the latest firmware changes.

Console test inputs: `tap in|out <UID>` (simulated card tap through the same decision path as the RC522 readers) and `motion <1|2>` (simulated PIR motion).
